# LOGESHWARAN WELDING & FABRICATION — Premium Website

An international-grade, modern, responsive website designed and developed for **Logeshwaran Welding & Fabrication**, located in **Thuraiyur, Tiruchirappalli, Tamil Nadu, India**.

Built with **Next.js (App Router)**, **TypeScript**, **Tailwind CSS**, **Three.js**, and **Lucide React**.

---

## 🌟 Key Features

1. **Cinematic Hero Experience**:
   - Dark industrial atmosphere with custom HTML5 Canvas welding spark particle engine.
   - Interactive Three.js 3D brushed stainless steel geometrical structure reacting to mouse motion.
   - Distinctive typography with Space Grotesk display headings and metallic gradient accents.
   - Location indicator: `THURAIYUR | TIRUCHIRAPPALLI`.

2. **Authentic Workshop & Client Project Showcase**:
   - Highlights the client's **real fabrication projects** sourced from workshop documentation:
     - *Stainless Steel Staircase Railing Installation* with wood accent post & sphere finial.
     - *Decorative Laser-Cut Tree & Floral Compound Safety Gate* with gold enamel finish.
     - *Workshop Fabrication of Stainless Steel Main Gate* with mirror polish buffing.
     - *Laser-Cut Sacred Ganesha Stainless Steel Sheet Panel* with Om contouring.
   - Filterable portfolio across 6 categories (*Staircase Railings, Stainless Steel Works, Gates & Grills, Decorative Metal Designs, Custom Fabrication, Workshop & Welding*).
   - Full-screen interactive image lightbox with keyboard controls (Esc, Arrow keys) and direct WhatsApp design inquiry button.

3. **Complete Services Catalog (9 Offerings)**:
   - Stainless Steel Staircase Railings
   - Stainless Steel Handrails
   - Balcony Railings
   - Stainless Steel Gates
   - Metal Gates and Grills
   - Decorative Laser-Cut Metal Designs
   - Custom Metal Fabrication
   - Residential and Commercial Welding
   - Custom Stainless Steel Works
   - Each with dedicated high-resolution local photography, material grade recommendations (SS 304 / SS 316 / Mild Steel), and one-click WhatsApp inquiries.

4. **Structured 4-Phase Work Process**:
   - `01 Discuss` → `02 Design` → `03 Fabricate` → `04 Deliver`.
   - Horizontal interconnected timeline on desktop, vertical card stack on mobile.

5. **Why Choose Us & Customer Experience**:
   - 6 core craftsmanship pillars (Precision Craftsmanship, Custom Design Solutions, Quality Materials, Attention to Detail, Professional Workmanship, Customer-Focused Service).
   - Illustrative client feedback cards and the brand banner: *"Every Project Matters. Every Customer Matters."*

6. **Direct WhatsApp Quote Estimator & Contact Hub**:
   - Click-to-call integration for all 3 business phone numbers:
     - `+91 91503 75567` (Primary & WhatsApp)
     - `+91 90952 40008` (Direct Inquiries)
     - `+91 99650 11126` (Workshop Support)
   - Client-side validated form that generates a formatted WhatsApp inquiry message addressed directly to Logeshwaran with celebration confetti.
   - Google Maps location navigation link.
   - Floating WhatsApp beacon button with quick inquiry tooltip.

7. **Production & SEO Ready**:
   - Zero external CDN dependencies — all images stored locally in `public/images/`.
   - LocalBusiness Schema (JSON-LD) for Thuraiyur / Tiruchirappalli local search rankings.
   - Dynamic `sitemap.xml` and `robots.txt`.
   - 100% clean production build with Next.js Turbopack, ready for instant one-click Vercel deployment.

## 🛠️ Tech Stack

- **Framework**: Next.js 16 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS v4
- **3D & Graphics**: Three.js & HTML5 Canvas Particle Engine
- **Icons**: Lucide React
- **Confetti**: Canvas Confetti

---

## 🚀 Running Locally

```bash
# 1. Install dependencies
npm install

# 2. Run local dev server
npm run dev
# Open http://localhost:3000 in your browser

# 3. Production build & test
npm run build
npm run start
```

## ⚙️ Centralized Configuration

All phone numbers, WhatsApp contact, addresses, map URLs, and services are centrally configured in:
`src/data/site.ts`
To change the primary WhatsApp receiving number, simply update `primaryWhatsAppNumber` in that file.
